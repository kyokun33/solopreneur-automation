# 🛠️ 고고플랙스 랜딩 페이지 Mockup 명세서: Anti-Loss Funnel 최종 버전

## 🎯 목표 및 컨셉
*   **목표**: 사용자에게 정량화된 손실($\text{₩}X$만원)을 인지시킨 후, 이를 스스로 해결할 수 없는 '구조적 문제'로 인식시켜 전문가의 진단(Diagnostic Report 예약)으로 유도.
*   **톤앤매너 변화**: **Red Panic (위기감)** $\rightarrow$ **Blue Authority (전문성/신뢰)**

## 🎨 디자인 시스템 요약
| 요소 | 스타일 정의 | 컬러 코드 | 비고 |
| :--- | :--- | :--- | :--- |
| Primary Background | Pure White / Light Gray | `#FFFFFF` / `#F5F5F7` | 깨끗하고 개방적인 느낌. 여백 최대화. |
| Loss Accent (Warning) | 손실, 리스크 경고 | `Warning Red (#CC3333)` | 위기감 극대화에만 사용. |
| Primary Accent (Trust/CTA) | 핵심 CTA, 해결책 제시 | `Tech Blue (#0066CC)` | 신뢰도와 권위를 상징하며 시선 집중. |
| Text Color | 본문 텍스트 | `Deep Charcoal (#1D1D1F)` | 가독성 최우선 원칙 준수. |

## 🖥️ 섹션별 와이어프레임 및 인터랙티브 명세 (Desktop View 기준)

### 🔴 Section A: Hero / Loss Shock (위기감 조성)
*   **레이아웃**: 중앙 집중형, 강렬한 대비를 사용한다.
*   **H1 Tag**: 가장 크게, `Deep Charcoal` 색상으로 배치하며, 경고 이모지를 활용한다.
    > 🚨 당신의 비즈니스가 지금 놓치고 있는 '진짜' 위험 비용은 얼마입니까?
*   **Loss Counter Widget (핵심)**: 페이지 중앙에 크기 최대로 배치.
    *   **애니메이션**: Opacity 0 $\rightarrow$ Fade-In Up & Count Up (필수).
    *   **표시값 구조**: [시간 손실분] + [리스크 비용]. 두 값을 분리하여 표시하고, 합산된 최종 금액 아래에 `Loss = 시간 * 가치` 공식을 작은 글씨로 강조.
    *   **디자인 강조**: 전체 영역의 배경을 은은하게 붉은 필터(Overlay)를 적용하거나, 경고 메시지 박스(`Warning Red`)를 사용하여 시각적 압박감을 준다.

### 🔵 Section B: Problem Amplification (문제 의식 증폭 - 빙산 효과)
*   **레이아웃**: 3-Column Grid 형태로 배치하며, 각 컬럼은 분리된 카드 배경 (`#F5F5F7`)를 가진다.
*   **H2 Tag**: Red Warning을 유지하면서도, 문제의 '원인'에 초점을 맞춘다.
    > 경고: 당신이 계산한 손실액($\text{₩}X$만원)은 빙산의 일각일 뿐입니다. 근본적인 시스템 오류가 문제입니다.
*   **3개 카드 컴포넌트 (예시)**:
    1.  **[카드 1] 데이터 사일로 리스크**: 설명과 함께 '비효율적'이라는 키워드에 `Warning Red`를 적용.
    2.  **[카드 2] 반복 업무 비용**: 시간 자원 손실을 강조하며, 이 부분에서만 작은 애니메이션 (시계가 빠르게 돌아가는 모션) 추가.
    3.  **[카드 3] Anti-Loss Funnel 부재**: '위기감 극대화' 시스템이 없다는 점을 지적하며 공포심 자극.
*   **인터랙션**: 각 카드에 마우스를 올릴 때(Hover), 해당 문제의 **실질적인 위험도(Risk Score)**가 팝업되어 표시되도록 설계한다.

### ✨ Section C: CTA / Solution (전문성 확립 및 전환 유도)
*   **레이아웃**: 페이지 하단 전체 너비를 사용하며, 배경색을 `#F5F5F7`로 변경하여 안정감을 준다.
*   **H3 Tag**: 위기감 조성 대신 '해결책'의 필요성을 전문적으로 제시한다.
    > 🚀 이 구조적 취약점을 해결하기 위한 **맞춤형 진단 보고서(Diagnostic Report)**가 필요합니다.
*   **핵심 CTA 버튼 (최종 목표)**:
    *   **버튼 문구**: `✅ 손실 원인 진단 보고서 받기 및 미팅 예약` [근거: 지난 의사결정 로그]
    *   **스타일**: `Tech Blue (#0066CC)`를 사용하여 강한 대비와 신뢰감을 제공. 크기는 페이지에서 가장 커야 하며, 호버 시 약간의 그림자(Soft Shadow) 애니메이션을 적용하여 클릭하고 싶게 만든다.
*   **신뢰 요소 (Trust Signal)**: CTA 버튼 바로 아래에 작은 텍스트로 다음 내용을 배치한다.
    > "진단 보고서는 3단계 구조적 분석과 즉시 실행 가능한 개선 로드맵을 포함합니다."
