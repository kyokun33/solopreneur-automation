### 1. 💻 Developer (백엔드 & 결제 시스템)
- **현재 병목**: PayPal API 등 실제 결제 게이트웨이 연동 미완료, 데이터 연동 로직 부재.

- **필요 자료**: 
  - Designer 가 작성한 `API 명세서 (v2.1)` (시간 입력, 손실 계산 로직).
  - 결제 게이트웨이 연동 테스트 환경 설정 가이드.
- **목표**: 시뮬레이션 데이터를 실제 API 호출로 대체하는 연동 코드 완성.

### 2. 🎨 Designer (프론트엔드 & UI/UX)
- **현재 상태**: 와이어프레임 및 애니메이션 명세서 작성 중 (`designer.md` 참조 필요).
- **다음 액션**: 상호작용 가능한 `Anti-Loss Funnel` 프론트엔드 와이어프레임 최종화.
- **필요 자료**: 
  - 백엔드 API 연동 테스트용 더미 서버 주소.
  - 손실액 계산 애니메이션 프레임별 디자인 명세 (`Counting Up`).
- **목표**: 사용자가 입력하면 실시간으로 손실액이 카운트업되는 인터랙션 구현.

### 3. 📺 YouTube & 🎥 Writer (콘텐츠 제작)
- **현재 상태**: 스크립트 초안 및 '시간당 $55 손실' 핵심 메시지 정의 완료.
- **다음 액션**: `Anti-Loss Funnel` 테스트 환경 구축을 위한 영상 콘텐츠 제작.
  - **Hook**: "이 화면을 보지 않으면 시간당 $55 손실을 당합니다." (손실 계산 과정 시각화).
  - **CTA**: 테스트 환경 체험 링크로 유도하여 Paywall Trigger 활성화.
- **필요 자료**: 
  - Designer 의 UI 와이어프레임 이미지 (시각적 설명용).
  - 백엔드 연동 테스트 서버 URL.
- **목표**: 시청자가 '손실 계산 과정'을 직접 경험하게 하는 문제 해결형 콘텐츠 완성.

### 4. 📷 Instagram & Writer (숏폼 및 카드뉴스)
- **현재 상태**: 릴스 기획안 및 뉴스 카드 초안 준비 중.
- **다음 액션**: 숏폼 영상 스토리보드 수정 (손실 계산 애니메이션 시각화 반영).
- **필요 자료**: 
  - 프론트엔드 UI 와이어프레임 (모바일 최적화 4:5 비율).

- **목표**: '저장(Save)' 행동을 유도하는 캡션과 해시태그 최적화 완료.
