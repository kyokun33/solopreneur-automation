# 고고플랙스 Anti-Loss Funnel 최종 스토리보드 및 와이어프레임 명세서 (v2.0)

## 🎯 목표: Red Warning $\to$ Diagnosis $\to$ Report Request의 완벽한 사용자 여정 구축
### 💡 핵심 원칙
1. **Red Alert**: 시작부터 공포감 조성 (Glitch, Red Filter).
2. **Transparency**: 추상적 리스크를 `(시간 손실분 + 리스크 비용)`으로 정량화하여 신뢰 확보.
3. **Interaction**: 단순 문의가 아닌 '손실 점수 측정'이라는 참여형 위젯을 통해 데이터 수집 및 전환 유도.

---

### 🖼️ 섹션별 상세 와이어프레임 및 인터랙션 스펙 (개발자용)

**[섹션 1: Hero - Red Warning]**
*   **시각 요소:** Full-screen Glitch/Red Filter Overlay. 배경은 불안정하게 흔들리는(Jittering) 어두운 그레이톤.
*   **CTA 전 상태:** `비활성화 (Disabled)`, 마우스 오버 시 경고음 발생.

**[섹션 2: Loss Quantification]**
*   **UX 목표:** 사용자가 손실액을 '지식'으로 받아들이게 만든다.
*   **핵심 위젯:** [Loss Breakdown Widget] - 세 가지 리스크(데이터 주권, 편향성, XAI)를 각각 독립된 도넛 차트로 분리하여 배치. 각 차트 클릭 시 해당 리스크에 대한 상세 법적 근거와 최소 손실액을 팝업으로 제공한다.
*   **Transition:** 섹션 하단에서 '진단 필요'라는 문구와 함께 다음 단계로의 스크롤 유도(Scroll Indicator)를 강하게 배치한다.

**[섹션 3: Interactive Core - 진단 위젯 (Conversion)]**
*   **전환 트리거:** Red Filter가 투명해지며, 배경색이 `#F5F5F7`로 바뀌는 시각적 변화가 일어난다.
*   **위젯 동작 (Step-by-step):**
    1. **문제 선택:** 사용자가 3가지 리스크 중 가장 취약하다고 느끼는 항목을 체크한다.
    2. **시간 입력:** 해당 문제 해결에 필요한 '추정 노력 시간(Hours)' 슬라이더를 조작하게 한다. (예: "데이터 주권 문제를 해결하려면 최소한 XX시간의 전문가 검토가 필요합니다.")
    3. **결과 출력:** 최종적으로 위젯 하단에 `[현재 진단 결과: ₩XX만 규모의 리스크 + [YY] 시간의 전문 지식 부재]`를 명확히 표시한다. 이 숫자가 CTA 버튼의 근거 자료(Anchor Data)가 된다.
*   **최종 CTA:** 배경색 `#FFFFFF`, 버튼 색상 `#0066CC`. 텍스트: "손실 방지 및 전문가 진단 보고서 받기". 클릭 시 성공 애니메이션과 함께 다음 단계(폼 전송 모달 또는 페이지 이동)로 연결한다.
