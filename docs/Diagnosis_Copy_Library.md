# 🚨 데이터 무결성 스코어카드 (Anti-Loss Funnel) 카피라이팅 라이브러리 V2.0
## [최종 지시사항: 모든 문구는 기술적 전문성을 갖추되, 고객의 '손실'에 대한 공포와 위기감을 극대화해야 함.]

### 1. 메인 진단 점수(Score) 영역 카피 (The Score Display)
**[목표]:** 단순한 숫자 제시가 아닌, 이 숫자가 의미하는 **경제적 재앙의 수준**을 직관적으로 인지시킨다.

| 상태 | 일반 경고 문구 (X) | Anti-Loss Funnel 전용 카피 (O) | 활용 시점 |
| :--- | :--- | :--- | :--- |
| **Critical (0~49)** | 데이터에 심각한 문제가 있습니다. | ⚠️ **[심각 위험 경고] 시스템 무결성 마지노선 이탈.** 현 상태가 지속될 경우, 최소 3년 내 누적 매출 대비 **최소 25% 이상의 예측 불가능 손실**이 발생할 확률이 높습니다. 즉각적인 구조 조정이 필요합니다. | 스코어 게이지가 적색/심각한 오류 메시지가 나올 때. |
| **High Risk (50~74)** | 일부 데이터에 문제가 발견되었습니다. | 🚨 **[주의 단계] 핵심 API 레벨의 데이터 드리프트(Data Drift) 포착.** 주요 비즈니스 지표 A와 B 간의 연동성이 약화되고 있습니다. 이로 인해 향후 분기별 운영 비용 절감 효과가 기대치 대비 **최대 15%까지 감소**할 수 있습니다. | 경고 문구와 함께 '세부 분석 보기'를 유도할 때. |
| **Low Risk (75~100)** | 현재는 안전한 상태입니다. | ✅ **[안정 단계] 데이터 무결성 지표가 정상 범위 내에 포착되었습니다.** 다만, 업계 최적화 기준점 대비 미흡한 영역이 확인되므로, 선제적 점검을 통해 잠재적 리스크를 제거하시는 것을 권장합니다. (CTA: '최적화 가이드 받기') | CTA의 주 목적을 '보완'으로 전환하여 구매 유도. |

### 2. 세부 손실 예측 위젯(Loss Potential Breakdown) 카피
**[목표]:** 추상적인 '문제'가 아닌, 구체적인 **돈과 시간의 상실**로 치환한다. (기술 보고서처럼 작성)

*   **제목:** 데이터 단절이 초래할 수 있는 잠재적 손실 분석 (Potential Loss Analysis from Data Interruption)
*   **핵심 문구 템플릿:**
    > "현재 [데이터 항목명]의 **[API 스키마 위반율]%**가 비정상적으로 높게 측정되었습니다. 이는 내부 보고서 작성 시 데이터 불일치로 인해 평균 $\text{[X]} \text{원} \times \text{[Y]} \text{건}$ 규모의 수동 검토 시간 낭비 및 **결정적 의사결정 지연**을 초래합니다."
*   **특정 위반 항목 예시 (Hover 시 발현):**
    1.  **[위반 영역: 고객 여정 데이터]**: "고객 A의 구매 퍼널 데이터를 추적하는 과정에서 **로그 기록 누락(Missing Log Entry)**이 발견되었습니다. 이로 인해 '어떤 단계에서 이탈했는지'에 대한 정확한 분석 자체가 불가능해지며, 최적화된 리타겟팅 캠페인 설계가 원천 봉쇄됩니다."
    2.  **[위반 영역: 재무 보고 데이터]**: "재무 데이터를 취합하는 과정에서 **데이터 포맷 불일치(Schema Mismatch)** 위험이 감지되었습니다. 이는 회계 마감 시점의 검증 시간을 최소 3~5일 이상 지연시키고, 잠재적인 내부 감사 리스크를 키웁니다."

### 3. 최종 행동 유도 (CTA) 영역 카피
**[목표]:** 공포 $\rightarrow$ 희망(해결책)으로의 전환을 극대화한다. 단순히 '문의하기'가 아닌, **위험 회피에 대한 권리**를 부여하는 문구여야 한다.

*   **메인 CTA 버튼 (Primary Action):**
    > "잠재적 손실액 $\text{XXX}$원을 막기 위한 **맞춤형 진단 리포트(Anti-Loss Report) 받기**"
*   **서브 카피 (CTA 하부 설명):**
    > "본 진단 결과는 현재 시스템의 취약점을 객관적인 수치로 증명합니다. 저희 전문가가 제시하는 **'최적화된 데이터 무결성 로드맵'**을 통해 손실 위험을 최소화하십시오."
