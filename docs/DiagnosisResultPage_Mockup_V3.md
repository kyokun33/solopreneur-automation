# 📊 고고플랙스 - 데이터 무결성 진단 결과 페이지 명세서 v3.0

## 🎯 목표 및 핵심 전략
*   **목표:** 사용자에게 '지금 이대로는 위험하다'는 위기감을 최고조로 느끼게 하고, 고고플랙스의 컨설팅 서비스가 유일한 해결책임을 확신시키며 CTA(Call To Action)를 유도한다.
*   **핵심 전략 (Anti-Loss Funnel):** [위기 노출] $\to$ [손실 정량화 및 증명] $\to$ [해결 가능성 제시] $\to$ [CTA 실행].

## 🎨 디자인 원칙 준수 사항
1.  **애플 미니멀리즘**: 여백(Whitespace)을 극대화하여 정보의 가독성을 높이고, 핵심 요소에만 시선을 집중시킨다.
2.  **컬러 코드 일관성**:
    *   `#FFFFFF`: 기본 배경 (Primary).
    *   `#F5F5F7`: 섹션 구분/카드 배경 (Secondary).
    *   `#0066CC`: 신뢰/해결책/CTA 강조색 (Accent).
    *   `#CC3333`: 손실/경고 영역 (Loss Accent) — **최우선 사용**.
    *   `#1D1D1F`: 본문 텍스트 (Deep Charcoal).

### 2. Breakdown Section: 손실의 증명 (Trust Building)
*   **목적:** '왜 낮은 점수인지'를 투명하게 증명하여 서비스에 대한 신뢰도를 극대화한다. **가장 중요한 설득 구간.**
*   **레이아웃:** 두 개의 분리된 카드(Card Layout, `#F5F5F7` 배경)로 구성.

#### 2-A. 손실 Breakdown (Loss Potential) - *필수 섹션*
*   **제목:** "손실은 단순히 점수가 아닙니다. 누적된 구체적인 비용입니다."
*   **요소:** **[Interactive Pie Chart]** 또는 도넛 차트.
    *   **데이터 시각화:** 100%를 넘어서는 손실 규모를 보여줌으로써 공포감을 자극한다.
    *   **구조:** 전체 손실액 $\to$ (시간 손실분) + (리스크 비용).
    *   **색상 분할:** **리스크 비용(Risk Cost)** 부분은 반드시 `#CC3333`을 사용하여 시각적 경고를 준다. 시간 손실분은 중립적인 색상을 사용해 대비 효과 극대화.
*   **인터랙션 (Tooltip):** 차트의 특정 영역 위에 마우스를 올리면, "시간 부족으로 인한 기회비용: 150시간 $\times$ $55/h = $8,250"과 같이 **공식($=시각화)**이 명확히 표시되어야 한다.

#### 2-B. 진단 취약점 목록 (Vulnerability Points)
*   **제목:** "당신의 데이터에 존재하는 주요 위험 요소 Top 3"
*   **레이아웃:** 아코디언(Accordion) 형태의 리스트 카드.
*   **내용:** E2E 테스트 스펙에서 정의된 **실패 시나리오 기반**의 구체적인 문제점들을 나열한다. (예: '데이터 사일로화 위험', '수작업 의존도 과다').
*   **하이라이팅:** 각 카드의 제목이나 핵심 문구에는 `#CC3333`을 사용하여 경고 신호를 준다.
