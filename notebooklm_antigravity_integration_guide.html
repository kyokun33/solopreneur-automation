1. NotebookLM MCP Server 연동 (공식 MCP 구성 방식) 추천 1위

Antigravity IDE의 MCP(Model Context Protocol) 환경변수에 구글 쿠키 세션을 연결하여 안티그래비티 에이전트가 direct API를 호출하는 방식입니다.

  • 1단계: 크롬 브라우저에서 `notebooklm.google.com` 로그인 후 F12 (개발자 도구) -> Application -> Cookies 이동
  • 2단계: `__Secure-1PSID` 및 `SID` 쿠키 문자열 복사
  • 3단계: Antigravity MCP 설정파일(`mcp_config.json`) 환경변수 바인딩
    • {
  "mcpServers": {
    "notebooklm": {
      "command": "npx",
      "args": ["-y", "notebooklm-mcp"],
      "env": {
        "NOTEBOOKLM_AUTH_TOKEN": "구글_세션_쿠키_문자열"
      }
    }
  }
}
    2. Google Drive Desktop 실시간 수집 연동 (가장 안정적 방식) 추천 2위

    Antigravity가 보고서를 대표님 PC의 Google Drive 동기화 폴더에 자동 저장을 수행하고, NotebookLM에서 Google Drive를 소스로 연결하는 방식입니다.

    1. Antigravity가 생성하는 모든 `.txt` / `.pdf` 보고서를 `G:\내 드라이브\보고서\` 경로에 자동 출력
    2. NotebookLM의 [소스 추가] -> [Google Drive] 클릭 1회 연동
    3. 이후 파일이 수정될 때마다 NotebookLM이 구글 드라이브에서 100% 무인 자동 수집
    3. Playwright DOM 요소 정밀 추적 웹 자동화 개발용

    단순 마우스 좌표 클릭이 아닌, HTML 구조(`aria-label`, `CSS Selector`)를 정밀 지정하여 웹 UI를 100% 타격하는 방식입니다.

    page.click('button[aria-label="새 노트북 만들기"]')
page.fill('input[placeholder="제목 없는 노트북"]', '보고서')
page.click('button:has-text("소스 추가")')
