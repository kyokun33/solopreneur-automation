# 보험 관련 세로형(9:16) 유튜브 쇼츠 영상 제작 가이드라인

해당 규칙은 GA 보험 관련 숏폼 영상을 기획하거나 대본, 렌더링 스크립트를 작성할 때 항상 최우선으로 적용되어야 합니다.

## 1. 디자인 톤 (Design Tone)
- 신뢰감 있고 세련된 금융/보험 브랜드 느낌을 연출합니다. (미니멀, 절제된 컬러 팔레트: 네이비/딥블루 + 화이트 + 포인트 컬러 1개)
- 과도한 장식 없이 여백을 활용한 고급스러운 레이아웃을 사용합니다.
- 폰트는 가독성 높은 산세리프 계열을 사용하고, 굵기(Weight) 대비를 통해 핵심 단어를 강조합니다.

## 2. 텍스트 정렬 규칙 (Text Alignment & Wrapping)
- 모든 문구는 좌우 대칭 또는 좌측 정렬 기준으로 오와 열을 정확히 맞춰 배치합니다.
- 한 문장이 화면 중앙에서 어색하게 끊기지 않도록, 반드시 **의미 단위(어절/구)**로 줄바꿈 위치를 지정합니다.
- 한 줄에 들어가는 글자 수를 제한하여 자동 줄바꿈으로 인한 부자연스러운 절단을 방지합니다.
- 문장 전체가 한 화면 안에서 스크롤 없이 온전히 보이도록 텍스트 블록 크기를 화면 세이프존(상하좌우 10% 여백) 안에 맞춥니다.

## 3. 시간 구성 (Timing Structure)
- **0~5초**: 핵심 메시지(훅, Hook)가 화면에 바로 노출되어야 합니다. 이 구간 안에 시청자가 전체 문장을 다 읽을 수 있는 텍스트 분량으로 철저히 제한합니다.
- **5초 이후**: 세부 설명이 이어지되, 각 장면 전환 시에도 동일한 정렬/여백 규칙을 유지합니다.
- 영상 끝까지 스크롤이나 추가 조작 없이 자연스럽게 시청 완료되는 흐름으로 구성합니다.

## 4. 출력 형식 (Output Format)
- 세로 비율 **1080x1920 (9:16)**
- 쇼츠 기획/스크립트 작성 시 각 장면(씬)마다 다음 요소를 명시하여 제시할 것:
  - 배경 디자인
  - 텍스트 내용
  - 줄바꿈 위치 (의미 단위)
  - 노출 시간(초)
