# 🚀 1인 기업 AI 무인 자동화 스킬 (Solopreneur Automation Skill)

본 스킬은 1인 기업가의 업무 시간을 70% 이상 단축하고, 무인 마케팅·전자책 자동 발송·B2B 영업 제안 및 디지털 자산 연금 수익화 파이프라인을 구축할 때 사용하는 전용 스킬 가이드입니다.

---

## 📌 핵심 기능 및 모듈

1. **📄 고품질 PDF 전자책 빌더 (`build_ebook_pdf.py`)**
   - ReportLab 기반 A4 고화질 한글 PDF 자동 생성
   - 3D 커버 및 인포그래픽 4단계 실행 가이드 내장
   - 눈이 편안한 오프화이트/네이비 톤 앤 매너 렌더링

2. **🌐 1초 복사 웹 뷰어 및 포털 (`ebook_reader.html` & `sales_portal.py`)**
   - 001~100선 파트별 카테고리 탭 탐색
   - 1초 프롬프트 클립보드 복사 버튼
   - 29,000원 결제 시 PDF 1초 자동 다운로드 연동 백엔드 (FastAPI)

3. **📢 바이럴 마케팅 팩 (`marketing_campaign_pack.md`)**
   - 네이버 블로그, 카카오톡 오픈채팅 3줄 요약
   - 디스코드/커뮤니티 홍보 카피
   - 숏폼(TikTok/Shorts/Reels) 30초 성우 대본 패키지

---

## ⚡ 스킬 실행 지침

- 새로운 1인 기업 수익화 아이템 생성 요청 시 **[100선 커스텀 프롬프트 템플릿]**과 연동하여 파이프라인 자동 구축.
- 시각적 가독성 최적화를 위해 **100% 선명한 벡터 CSS 파이프라인**과 **한글 가이드**를 최우선 적용.
