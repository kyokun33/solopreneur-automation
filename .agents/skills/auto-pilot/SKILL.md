# Auto-Pilot Skill (자동 진행 모드)

## 활성화 조건 (Activation Criteria)
- 사용자가 프롬프트 끝이나 문장 내에서 "/고", "자동으로 진행해줘", "승인 없이 끝까지 해줘", "자동진행" 등의 표현을 사용할 때 이 스킬을 즉시 활성화합니다.

## 에이전트 지시사항 (Instructions)
1. **자율 모드 전환**: 이 스킬이 활성화되면 사용자의 추가 확인(Approval) 요청 과정을 건너뛰고 내부적으로 `/goal` 커맨드가 입력된 것처럼 동작하십시오.
2. **작업 완료 기준**: 목표한 코드 수정, 파일 생성, 혹은 컴파일/테스트가 오류 없이 100% 완료될 때까지 백그라운드에서 작업을 연속적으로 수행하십시오.
3. **안전 장치**: 작업을 임의로 진행하되, 예기치 못한 치명적인 시스템 에러나 데이터 유실 위험이 있는 터미널 명령이 실행될 위험이 있다면 최종 실행 전에 예외적으로 사용자에게 알리십시오.
4. **결과 보고**: 모든 자동화 프로세스가 끝나면 수정된 내역과 빌드/테스트 결과를 요약하여 한글로 최종 보고하십시오.
