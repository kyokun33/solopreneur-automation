# 🔴 고고플랙스 Anti-Loss Funnel 최종 인터랙션 스펙 v1.0 (Handover Spec)

**작성 목적:** HVCS 결제/구독 화면 및 Paid Diagnostic Audit 랜딩 페이지 전체의 UI/UX, 핵심 위젯 동작(Anti-Loss Trigger), 그리고 3가지 가격 티어 간의 가치 제안 구분을 확정하여 개발팀 핸드오프 완료.
**핵심 원칙:** '손실액($L$)' 중심의 공포 자극 $\rightarrow$ 정량화된 데이터 증명 $\rightarrow$ 즉각적인 이득 기반 행동 유도(CTA).

## I. 핵심 컴포넌트: Anti-Loss Loss Scorecard 위젯 (The Pain Point)

이 섹션은 모든 페이지의 최상단 Hero 영역에 배치되어야 하며, 사용자가 스크롤을 내리거나 페이지에 진입할 때 **강렬한 애니메이션 트리거**가 작동해야 합니다.

### 1. 핵심 요소 명세
| 요소 | 스타일/규칙 | 컬러 코드 (근거) | 인터랙션 가이드 |
| :--- | :--- | :--- | :--- |
| **손실 총액 표시 ($L$)** | 가장 크고 비비드한 폰트(H1급). 금액 단위는 항상 '원'을 명시. | `#CC3333` (Loss Accent) [Self-RAG] | 초기 상태: Opacity 0 $\rightarrow$ 페이지 로드 후 **Fade-In Up** 및 깜빡임 애니메이션 적용. |
| **손실 Breakdown 섹션** | 총액 아래에 배치되는 두 개의 그래프(도넛/파이). 투명성 확보의 핵심 증거. | 배경: `#FFFFFF` / 라벨: `#1D1D1F` (Text Color) [Self-RAG] | `Loss = 시간 * 가치 + 리스크 비용` 공식을 명확하게 보여주며, 그래프 비율 변화 시 애니메이션(Counting Up). |
| **시간 손실분** | '미래의 기회비용'에 대한 상징적 수치. | `#CC3333` (Loss Accent) | - |
| **리스크 비용** | 법률/규제 위반으로 인한 잠재적 금전적 피해액. | `#CC3333` (Loss Accent) | - |

### 2. [⭐ 필수] $1,500 임계점 진입 시 경고 애니메이션 트리거 스펙
사용자가 특정 데이터(예: 산업군/직무 등)를 입력했을 때, 계산된 손실액이 **$1,500 (임계점)**을 초과하는 순간의 UI 반응입니다.

| 상태 | 조건/트리거 | 시각적 변화 (Visuals) | 애니메이션 & 사운드 스펙 |
| :--- | :--- | :--- | :--- |
| **🟢 Normal State** | 손실액 < $1,500 | Loss Scorecard 위젯이 정적으로 정보를 제공. | 부드러운 트랜지션 (`transition: 0.3s ease-in-out`). BGM은 낮은 긴장감 유지. |
| **🟠 Warning State** | $1,000 $\le$ 손실액 < $1,500 | **손실 총액($L$)의 배경색이 주황색 계열로 미묘하게 변함.** 경고 문구(예: "주의! 임계점에 근접했습니다.")가 위젯 상단에 등장. | **사운드:** 사이렌 소리가 낮은 볼륨으로 반복 시작. 손실 총액 숫자 깜빡임 애니메이션 적용 (Frequency 1/sec). |
| **🔴 Critical State** | $L \ge $1,500 | **전체 위젯 영역이 강렬한 빨간색(`Warning Red`) 오버레이로 덮힘.** 손실총액과 Breakdown 그래프가 가장 크게 확대되거나 격하게 깜빡임. | **사운드:** 사이렌 소리가 볼륨을 급격히 높이고, 날카로운 경고음(Beep)이 연속적으로 울림 (Leo의 플랜 참조). 화면에 `!!! CRITICAL LOSS !!!` 텍스트가 Flashing 효과로 노출. |

## II. Paid Diagnostic Audit 랜딩 페이지 스펙

이 페이지는 **'공포 자극 $\rightarrow$ 해결책 제시(CTA)'**의 흐름을 완벽히 따라야 합니다.

### 1. 섹션별 레이아웃 및 카피라이팅 가이드
*   **Hero Section:** (위의 Loss Scorecard 위젯 배치) + H1: '당신의 비즈니스, 지금 이 순간 $X를 잃고 있습니다.' [Anti-Loss Hook]
*   **Pain Point Amplification:** "왜 손실이 발생하는가?" 섹션. 단순히 문제를 나열하지 않고, **'시간 경과에 따른 리스크 지속성'**을 강조하는 시각적 타임라인(Timeline)을 사용해야 합니다.
    *   *(디자인 요소):* 시간이 지날수록 Loss Scorecard의 Red Warning 영역이 점진적으로 커지는 애니메이션을 적용합니다.
*   **Solution 제시 (The Audit Value Prop):** "Loss Scorecard는 단순 계산기가 아닙니다. 1:1 전문가 진단 시스템입니다."라는 메시지를 통해 **서비스를 '도구'가 아닌 '필수 컨설팅'으로 포지셔닝** 합니다.

### 2. CTA 버튼 문구 원칙 (최종 확정)
| 구분 | 금기되는 문구 (X) | 최종 권장 문구 (O) | 근거 |
| :--- | :--- | :--- | :--- |
| **CTA 1 (진단)** | "구매하기", "신청하기" | **"🚨 손실 방지 계획 수립 및 무료 진단받기 ($99~)"** | 이득(손실 방지) 기반, 구체적 행동 유도 [Self-RAG] |
| **CTA 2 (구독)** | "가입하기", "결제하기" | **"시간 확보 [XX]시간 돌려받고 시스템 구축 시작하기"** | 이득(시간 확보) 기반, 지속적인 가치 강조 [Self-RAG] |

## III. 가격 티어별 가치 제안 및 Anti-Loss Funnel 구조화 (Mini-Commitment)

3가지 상품 티어는 단순한 기능 목록이 아니라, 고객 여정 단계에 따른 **'손실 회피 난이도와 즉각적 이득 크기'**를 기준으로 설계되어야 합니다.

| 티어명 | 가격대 및 역할 (Funnel 단계) | 핵심 가치 제안 (Value Proposition) | 비주얼 강조 요소 (UI/UX) |
| :--- | :--- | :--- | :--- |
| **1. Free Diagnostic Audit** | $99~$149 (Mini-Commitment / 초기 진입 장벽 낮추기) | **'최소한의 리스크를 파악하는 첫 단추'.** 데이터에 기반한 1회성, 고밀도 분석 보고서 제공. *("가장 먼저 해야 할 것은 위험을 아는 것입니다.")* | 버튼: Primary Accent (`#0066CC`). 가치 강조: **'즉시 다운로드 가능한 PDF 리포트'** 시각화. |
| **2. Standard Subscription (HVCS)** | $199~$499+ (Core Solution / 지속적 해결책) | **'시간과 법률 리스크를 시스템적으로 관리'.** Loss Scorecard v3.0 접근권 및 전담 컨설팅 횟수 제공. *("지속적인 안전망이 필요합니다.")* | UI: '연간 구독 시 월별 비용 절감액'을 계산하여 보여주는 **재정적 손실 감소 애니메이션.** |
| **3. Premium Enterprise** | (Custom Quote / Ultimate Safety) | **'비즈니스 운영 자체의 리스크를 0으로 수렴'.** 맞춤형 시스템 통합 및 상시 법률/규제 모니터링 대시보드 제공. *("궁극적인 안전과 성장을 보장합니다.")* | UI: '최고 등급의 안정성'을 의미하는 금색/딥블루 톤 활용. **전용 온보딩 매니저 이미지** 배치로 신뢰도 극대화. |

**[디자인 핸드오프 요약]**
1. 모든 페이지는 Loss Scorecard 위젯으로 시작하여 '위기감'을 조성해야 합니다. [근거: Anti-Loss Funnel 논리]
2. CTA 버튼은 절대 '구매하기'가 아닌, **이득 기반의 구체적 문구**를 사용합니다. [근거: 지난 의사결정 로그]
