# 📊 인스타그램 콘텐츠 성과 측정 기록지 (Personal Data Leak Risk)

**[콘텐츠명]** 개인정보 유출 리스크 경고 (Anti-Loss Funnel Ver.1)
**[발행일]** YYYY-MM-DD
**[목표 지표(KPI)]** Save Rate (최우선), CTA Click Through Rate (2순위), Comment Ratio

---

## 📈 초기 데이터 트래킹 항목

| 구분 | 측정 기준 | 목표값 (Goal) | 실제 값 | 분석 및 코멘트 |
| :--- | :--- | :--- | :--- | :--- |
| **도달률(Reach)** | 총 노출 대비 도달한 계정 수 | 15% 이상 | | *전체 트래픽 흡수력 측정* |
| **저장률 (Save Rate)** | 게시물 저장 수 / 도달 계정 수 | **최소 5%** | | **(가장 중요!)** 콘텐츠의 가치/정보 밀도 평가. '이건 나중에 봐야겠다'를 유발했는지 확인. |
| **댓글 반응 (Comment)** | 댓글 수 및 질적 분석 (🚨 이모티콘 등) | 최소 15개 이상 | | 커뮤니티 참여 및 즉각적인 공감대 형성 측정. CTA 질문을 던졌는지 확인. |
| **CTA 전환율** | 프로필 링크 클릭 / 총 도달 대비 비율 | 0.5% 이상 | | 궁극적 비즈니스 목표 달성 여부. 후크와 리스크 강조가 충분했는지 평가. |

---

## 💡 인사이트 추출 가이드라인 (Actionable Insights)
*   **Save Rate > 목표값일 경우:** "후크 문구의 공포감 증폭" 또는 "체크리스트 정보 구체화" 전략을 강화해야 함.
*   **CTA 전환율 < 목표값일 경우:** 'Paid Diagnostic Audit'가 제공하는 **최종 가치(Value Proposition)**를 캡션 초반에 더 강하게 제시할 필요가 있음.
*   **댓글 반응이 적을 경우:** 질문형 후크(예: "당신의 가장 취약한 데이터는 무엇인가요?")를 다음 콘텐츠에 필수적으로 포함해야 함.
