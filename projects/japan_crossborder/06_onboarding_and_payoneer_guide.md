## 1. 홈택스 영문 사업자등록증명원 즉시 발급 절차

3. 기본 인적사항 확인:
   - 사업자등록번호: `315-07-72875` (고고플랙스) 선택
4. **발급유형 및 영문 정보 입력 (핵심):**

## 2. Payoneer(페이오니아) 가입 및 JPY 수취 가상계좌 개설 가이드

Payoneer는 일본 마켓플레이스(아마존 재팬, 큐텐재팬 등)에서 발생한 **엔화(JPY) 매출을 국내 계좌로 정산받기 위한 글로벌 가상계좌**입니다.

### 2.1 사전 준비물 (스캔/PDF)
1. **대표자 신분증:** 여권 권장 (네 모서리가 모두 보이게 고해상도 촬영)
2. **홈택스 영문 사업자등록증명원 PDF** (1단계에서 발급한 파일)
3. **주소 증빙 서류 (요청 시):** 최근 3개월 이내 발급된 **정부24 영문 주민등록등본** 또는 사업장 임대차계약서/공과금 고지서
4. **국내 인출용 본인/사업자 은행 계좌:** 대표자(`고석효`) 또는 `고고플랙스` 명의의 국내 입출금 계좌 (영문 계좌개설확인서 준비 시 승인 빠름)

### 2.2 회원가입 단계별 입력 가이드
1. **Payoneer 공식 사이트** 접속 → **[가입하기]** 클릭
2. **비즈니스 유형 선택:**
   - 목적: **`온라인 셀러 / 이커머스 셀러 (Online Seller)`** 선택
   - 월 예상 매출 구간: 초기 테스트 구간 선택 (예: `$10,000 미만`)
   - 사업자 형태: **반드시 `기업 / 개인사업자 (Company / Registered Business)`** 선택 *(개인(Individual)으로 잘못 선택 시 추후 사업자 계좌 연동에 제약 발생)*
3. **사업자 정보 입력 (모두 영문):**
   - 법적 사업자명(Legal Business Name): `GOGOFLEX`
   - 사업자 형태: `Sole Proprietorship` (개인사업자)
   - 대표자 성명: 여권과 동일 (`Seokhyo Go` / First Name: `Seokhyo`, Last Name: `Go`)
   - 사업장 주소: 영문 사업자등록증명원과 100% 동일한 영문 주소
   - 휴대폰 인증: `+82` 선택 후 `10-XXXX-XXXX` SMS 인증
4. **보안 및 국내 은행 계좌 연결:**
   - 로그인 비밀번호·보안 질문 설정
   - 정산금 인출용 **국내 은행 계좌(KRW)** 등록 (은행명 영문 선택, 계좌번호 입력, 예금주명 `Go Seokhyo` 입력)
5. **인증 센터(Verification Center) 서류 업로드:**
   - 가입 직후 로그인 → **[설정] → [인증 센터]**에서 요청하는 항목(여권 사본, 영문 사업자등록증명원, 글로벌 결제 설문지 등)을 즉시 업로드.

### 2.3 JPY(일본 엔화) 수취 가상계좌 개설 및 확인
1. Payoneer 계정 승인 완료 후 상단 메뉴 **[받기(Receive)] → [수취 계좌(Receiving Accounts)]** 이동
2. 통화 목록에서 **`JPY (Japanese Yen)`** 선택 및 개설 신청 *(미활성 시 고객센터/계정 내 '계좌 추가 요청' 진행)*
3. 발급 완료 후 일본 현지 가상계좌 정보 확인:
   - **은행명 (Bank Name) / 지점명 (Branch Name) / 계좌유형 (예: 普通) / 계좌번호 (Account Number) / 예금주명 (Account Holder Name)**
4. **증빙서류 저장:** Qoo10 Japan 등 마켓 제출을 위해 Payoneer 대시보드 내 **[계좌 상세 화면 스크린샷]** 또는 **[계좌 확인서(Bank Confirmation Letter) PDF]**를 다운로드해 둡니다.

### 2.4 간이과세자 주의사항 (매우 중요)
- **가입 가능 여부:** 간이과세자도 정식 개인사업자(`Registered Business`)이므로 Payoneer 가입 및 JPY 계좌 개설에 **아무런 제한이 없습니다.**
- **부가세 매입세액 환급 불가 유의:** 간이과세자는 일반과세자와 달리 국내 사입 시 부담한 부가세(10%)를 전액 환급받지 못합니다. 따라서 **`01_market_and_sourcing.md` 및 `04_business_plan_roadmap.md`의 마진 시뮬레이션 적용 시, 사입 원가는 반드시 '부가세 포함 실제 매입가' 기준으로 계산**해야 실제 순마진(25~35%+) 왜곡을 방지할 수 있습니다. *(수출 영세율 적용 및 연 매출 확대 시 추후 일반과세자 전환을 세무사와 검토하세요.)*
- **휴면 수수료 유의:** Payoneer는 최근 12개월간 입금액이 기준(통상 $2,000 상당) 미만일 경우 연회비가 부과될 수 있으므로, 큐텐재팬 초기 정산금 수취를 위해 **J·QSM 직접 정산(국내 계좌/외화통장)과 Payoneer 연동 비용을 비교**해 활용하세요.

## 3. Qoo10 Japan(J·QSM) 셀러 입점 신청 가이드

큐텐재팬은 초기 입점비·월 고정비가 **0원**이며 한국어 관리자(`J·QSM`)를 제공해 1인 셀러 첫 채널로 가장 적합합니다.

### 3.1 입점 전 필수 준비 서류 4종
1. **사업자등록증 사본** (국문, 3개월 이내 발급본 권장 — `고고플랙스 / 315-07-72875`)
2. **대표자 신분증 사본** (여권, 주민등록증, 운전면허증 중 1부)
3. **정산용 통장 사본**
   - *국내 은행 계좌(원화/엔화 외화통장) 사용 시:* 통장 사본 또는 인터넷뱅킹 계좌개설확인서 (`고석효` 또는 `고고플랙스` 명의 일치 필수)
   - *Payoneer JPY 계좌 사용 시:* Payoneer 계좌 상세 화면 캡처 또는 계좌 확인서(Bank Confirmation Letter) 제출
4. **통신판매업신고증**
   - 아직 미발급 상태라면 **정부24(gov.kr)** 또는 **인천광역시 서구청**을 통해 온라인 신청 가능(구매안전서비스 이용확인증 필요 — 사업자 계좌 연동 에스크로 또는 오픈마켓 제공 구매안전확인증 활용).

### 3.2 J·QSM 입점 신청 단계
1. **Qoo10 Japan 판매자 가입 페이지**(`https://qsm.qoo10.jp/`) 접속 → **[판매자 등록(Seller Registration)]** 클릭
2. **회원 유형 및 사업자 정보 입력:**
   - 판매자 구분: **`법인/개인사업자 (Business)`** 선택
   - 국가: `Republic of Korea (한국)`
   - 사업자등록번호: `3150772875` (`-` 제외 입력 확인)
   - 상호명/대표자명: 사업자등록증과 동일 입력 (영문란에는 `GOGOFLEX`, `Go Seokhyo`)
3. **정산 계좌 정보 입력:**
   - **선택 A (초기 추천·단순):** 국내 사업자/대표자 계좌 직접 등록 (출금 시 회당 150엔 + 국내 은행 타발송금 수수료 확인)
   - **선택 B (아마존 등 멀티채널 통합용):** Payoneer JPY 수취 계좌 정보 입력 (예금주명은 **영문 대문자**로 정확히 기입)
   - 자동 정산 출금 주기 설정: `주 1회` / `격주 1회` / `월 1회(마지막 수요일)` 중 선택
4. **서류 업로드 및 심사 대기:**
   - 사업자등록증, 신분증, 통장 사본(또는 Payoneer 확인서) 파일 첨부 후 제출 (심사 보통 3~5영업일 소요).

### 3.3 [중요] 통신판매업 신고증 승인 후 업로드 위치
입점 신청 단계에서 통신판매업신고증 첨부란이 별도로 없거나, 입점 승인 완료 후 보완 제출해야 하는 경우 아래 경로에 업로드합니다.
- **업로드 경로:** **J·QSM 로그인 (`https://qsm.qoo10.jp/`) → 상단 메뉴 [기본정보] → [나의 정보] → 사업자 정보/서류 관리 영역** 내 **[통신판매업신고증]** 첨부란에 PDF/이미지 업로드 후 저장.
- *참고:* 해외(한국) 사업자로 입점 시 통신판매업신고증 미제출 상태면 상품 노출이나 정산 출금 단계에서 보완 요청이 올 수 있으므로, 승인 직후 즉시 업로드해 두는 것을 권장합니다.

## 4. Qxpress(큐익스프레스) 셀러 계정 연동 및 첫 출고 테스트 설정

큐텐재팬 주문이 발생하면 큐텐 물류 자회사인 **Qxpress**를 통해 한국에서 일본 고객에게 직배송합니다.

### 4.1 J·QSM 내 Qxpress 연동 및 설정
1. **J·QSM 로그인 → [기본정보] → [배송/물류 설정] (또는 Qxpress 이용 신청 메뉴)** 이동
2. **Qxpress 이용 신청 및 약관 동의:**
   - `Qoo10 ID`와 사업자 정보(`고고플랙스 / 315-07-72875`) 연동 확인
3. **출고지(반송지) 및 배송비 템플릿 설정:**
   - **배송 방법:** `Qxpress Standard` (평균 2~5일) 기본 설정 권장 *(경량 초저가 상품은 Economy 비교)*
   - **배송비 조건:** 무료배송(판매가에 포함) 또는 조건부 무료배송(예: 3,000엔 이상 무료) 세팅
   - **발송 국가:** `Korea (한국)` 지정

### 4.2 첫 출고 테스트 프로세스 (인천 서구 사업장 강점 활용)
1. **주문 접수 및 송장(라벨) 출력:**
   - J·QSM **[배송관리] → [배송요청]**에서 주문 확인 → **[발주확인]** → **[Qxpress 라벨(바코드) 출력]**
2. **포장 및 라벨 부착:**
   - 완충재(에어캡) 포장 후 **Qxpress 전용 바코드 라벨**을 박스 겉면에 부착 (수취인 이름·주소·품명·가격 영문/일어 정확히 기재 확인 — `16,666엔` 이하 면세 범위 체크)
3. **집하센터 입고 (2가지 방식 중 선택):**
   - **방식 ① 국내 택배 이용:** 내 박스 안에 바코드 라벨이 붙은 개별 소포들을 합포장한 뒤, 국내 택배(CJ대한통운/우체국 등)로 **Qxpress 인천 집하센터(영종도 등 J·QSM 공지 최신 센터 주소 확인)**로 발송.
